## ✨ Features

- 🎯 Advanced movie search
- 📱 Full Responsive Project
- 🌙 have Dark & Light Mode 
- 🔍 Filter by genre, year, rating, director, country, age group, actor, quality, etc.
- 📊 Movie recommendations based on taste

## 🛠️ Technologies

HTML , CSS , JavaScript , Json
